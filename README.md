# Footy Evo — официальный сайт

Статическая промостраница Footy Evo в фирменном визуальном стиле приложения Phoenix Studio.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий с именем `ВАШ_ЛОГИН.github.io`.
2. Загрузите **содержимое этой папки** в корень репозитория, сохранив папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
6. После публикации проверьте сайт и файл `https://ВАШ_ЛОГИН.github.io/app-ads.txt`.

## Структура

- `index.html` — адаптивная страница Footy Evo.
- `app-ads.txt` — файл авторизации рекламных продавцов. Содержимое исходного файла сохранено без изменений.
- `assets/` — изображения из предоставленного фирменного промоматериала.

Важно: файл `app-ads.txt` должен находиться в корне домена. После публикации откройте его URL в браузере и убедитесь, что отображается текстовый список строк, а не страница 404.
